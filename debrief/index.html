Crosscheck watches the pilots the way a monitoring pilot does: it hears what was said, reads what was set on the panel through a camera, and watches what the aircraft is doing — and speaks up when they disagree. Each run below was flown in X-Plane 12 and recorded; this page replays it.

Crosscheck never reads the simulator's data. It sees the cockpit displays as camera frames (read with Apple's on-device text recognition) and hears speech through Muse Voice Transcribe. The dashed grey lines are X-Plane's own values, recorded only to score the run. Voices are synthetic (Meta MMS-TTS). Every value on this page comes from the recording in replay/; rebuild with uv run python cli.py debrief.
